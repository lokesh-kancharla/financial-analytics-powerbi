# Financial Analytics & Power BI

End-to-end financial analytics portfolio project combining data preparation, quantitative analysis, SQL/Python workflows, and interactive Power BI reporting.

## Project Goal
Build a professional financial analytics solution that converts market and company data into decision-ready insights through reproducible data preparation and interactive visualization.

## Flagship Project — S&P 500 Financial & Market Analytics
The planned flagship study will analyze public market data to explore company and sector performance, returns, volatility, trends, and relative performance.

### Planned Analysis
- Clean and transform market/company data with Python.
- Create reusable analytical tables and measures.
- Analyze returns, volatility, drawdowns, sector performance, and company rankings.
- Build interactive Power BI pages for executive overview, sector analysis, company drill-down, and trends.
- Document DAX measures, assumptions, data lineage, and analytical methodology.

## Technology
Power BI • DAX • Python • Pandas • SQL • Excel • Power Query
